# Leave-Tracker-App-Salesforce
# 🔵 Leave Tracker App — Salesforce LWC

A full-featured Leave Management App built on Salesforce Lightning Platform.

## 📌 Features
- ✅ Employee leave submission with real-time status tracking
- ✅ Role-based access for Employees & Managers
- ✅ Manager approval/rejection with comment functionality
- ✅ Apex controllers, SOQL queries & LWC lifecycle hooks
- ✅ Responsive single-page experience in Salesforce Lightning

## 🛠️ Tech Stack
- Lightning Web Components (LWC)
- Apex Controllers
- SOQL
- Salesforce Lightning Platform
